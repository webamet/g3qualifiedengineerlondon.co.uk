RENDERING RULES
Metadata has one title, one description, one canonical, robots and social head. JsonLd emits one composed graph from the same visible page record. Do not add a duplicate schema plugin or hand-edit the reference graphs independently of content.
All body copy must appear in initial HTML. Do not defer the whole website to client-only hydration. Hydrate only interactive controls such as menu, form or search.
ContentSections renders heading, paragraphs, optional bullets and optional table fields in normal semantic HTML. Never render attachment instructions or private setup flags. FAQBlock uses accessible details/summary or buttons with complete ARIA state; the answer text matches the supplied short answer exactly. Every displayed FAQ section has id=faqs, once per page.
GuidePage uses the page answer, source note and actual page-specific byline/review fields. Until approved personal records exist, use the business publisher. Do not display an empty portrait silhouette, Pending credential, default reviewer or invented date. A personal block is populated only from approved fields.
IndicatorTable renders page.indicatorTable when present, with a caption identifying the actual controller scope and a primary source link. For narrow screens use a labelled scroll container without making the entire page overflow.
CollectionPage renders exactly the supplied collection links so ItemList matches visible cards/list rows. Other page links are contextual RelatedReading, not another fake collection schema. BreadcrumbList matches the visible path labels.
Hubs include a working client search/filter across the supplied guide titles and summaries. Keep normal server-rendered links available without JavaScript. Do not create indexable search-parameter pages or empty filters as new routes.
The homepage must preserve #home, #main-content, #services, #areas, #about, #faqs and #contact. Footer and menus use real routes, not a wall of hash links to one section. Missing social/GBP/WhatsApp fields result in no link or icon, not href=#.

SVG / IMAGE RULES
Copy uploaded files using document 09. No source should point at /workspace, sandbox:, upload/, a local computer path or a made-up file. Render width/height to prevent layout shift. Above-fold key imagery loads eagerly; below-fold images load lazily. Do not invent srcset variants until actual derivative files exist. Show a product with its correct name, not as a photographed customer job. Keep imagery within native resolution, using contain for product references.
CylinderExplainer is an original responsive SVG/HTML concept diagram showing the roles of storage, heat input, expansion, inlet controls and visible relief discharge. Clearly label it as a concept overview, not a plumbing/wiring installation schematic. Do not hardcode a universal physical layout or numeric pressure for every cylinder.
Use the supplied original wordmark and inverse vector. The social preview is a real 1200x630 PNG. Validate the asset dimensions and filenames before rendering metadata.

SERVER CONNECTION BOUNDARY
The default draft/copy/email form is intentional and fully functional for the stated workflow. Never change it to a fake success state. It prepares a message and the user sends it through their email provider. Phone/email links remain usable without JavaScript.
If an actual authorised backend is connected, keep an independent delivery service, validate on the server, enforce length limits and spam controls, hold credentials in server secrets and verify owner-recipient receipt. Do not claim this handoff already connected SMTP, Resend, a database or an inbox. Update actual privacy/retention/processor records first. Avoid unnecessary data collection and advertising trackers.

SCHEMA BOUNDARIES
Organization is used while a verified full public postal address is absent. Do not output an invented LocalBusiness address or a separate office graph for each area. The factory can promote the entity to Plumber once a verified actual address is provided; Google local-business rich-result requirements still need external checks.
TechArticle is used for technical informational guides, Service for actual service/area enquiry pages, BreadcrumbList for visible breadcrumbs, ItemList for visible collection links, FAQPage only for supplied displayed FAQs. No merchant Product or Offer schema for informational product guides; no HowTo safety-valve DIY, fake Review/AggregateRating or unverified Person credentials. The 404 has no unnecessary content schema.
FAQPage remains valid vocabulary but is not a current Google FAQ rich-result feature. All schema proof in document 08 is generated mechanically and has not been passed through an external Google validator here. Bolt must inspect final HTML and report real external validation accurately.

ROUTING AND HOSTING
Keep clean paths exactly as supplied, using a consistent canonical without trailing slash except root. Select the Astro build/hosting configuration that serves these clean paths correctly. Test actual HTTP behaviour after deployment: known routes 200, unknown routes 404. Do not add a global SPA fallback rewriting every unknown path to index.html with 200. Test the four protected paths and any supplied later historical redirects.
A preview host remains noindex,follow. In production, generate only the 111 supplied indexable routes. Author approval and legal flags are handled explicitly, and any later changes must regenerate metadata/schema/sitemap counts. Do not publish private handoff or verification files.

export function canonical(site, page) {
  if (!page.path.startsWith('/') || page.path.includes('?') || page.path.includes('#') || page.path.includes('..')) throw new Error('Invalid canonical path');
  return site.domain.replace(/\/$/, '') + page.path;
}
export function serializeJsonLd(value) {
  return JSON.stringify(value).replace(/</g, '\\u003c').replace(/>/g, '\\u003e').replace(/&/g, '\\u0026').replace(/\u2028/g, '\\u2028').replace(/\u2029/g, '\\u2029');
}
export function metadata(site, page, options = {}) {
  const url = canonical(site, page);
  const production = options.production === true;
  const indexable = page.indexable === true && (!page.approvalRequired || site.author.publicProfileApproved === true);
  return { title: page.title, description: page.description, canonical: url, robots: production && indexable ? 'index,follow,max-image-preview:large' : 'noindex,follow', lang: 'en-GB', ogType: page.type === 'article' ? 'article' : 'website', ogImage: site.domain + '/images/g3-social-preview.png', ogImageWidth: 1200, ogImageHeight: 630, twitterCard: 'summary_large_image' };
}
export function schema(site, page) {
  if (page.type === 'notfound') return { '@context': 'https://schema.org', '@graph': [] };
  const root = site.domain.replace(/\/$/, '') + '/';
  const url = canonical(site, page);
  const orgId = root + '#organization';
  const websiteId = root + '#website';
  const pageId = url + '#webpage';
  const org = { '@type': 'Organization', '@id': orgId, name: site.name, url: root, telephone: site.phoneE164, email: site.email, description: site.positioning, logo: { '@type': 'ImageObject', url: root + 'images/g3-qualified-engineer-logo.svg' }, areaServed: { '@type': 'City', name: 'London' } };
  const ownedSocial = Object.values(site.socialProfiles || {}).filter(x => typeof x === 'string' && /^https:\/\//.test(x));
  if (ownedSocial.length) org.sameAs = ownedSocial;
  // Promote to a local business only after the actual public postal address is verified.
  if (site.address?.verified === true && site.address.streetAddress && site.address.postalCode) {
    org['@type'] = ['Organization', 'Plumber'];
    org.address = { '@type': 'PostalAddress', streetAddress: site.address.streetAddress, addressLocality: site.address.addressLocality, postalCode: site.address.postalCode, addressCountry: 'GB' };
    if (Array.isArray(site.openingHours) && site.openingHours.length) org.openingHoursSpecification = site.openingHours;
  }
  const website = { '@type': 'WebSite', '@id': websiteId, url: root, name: site.name, publisher: { '@id': orgId }, inLanguage: 'en-GB' };
  const kinds = { home: 'WebPage', collection: 'CollectionPage', contact: 'ContactPage', about: 'AboutPage', policy: 'WebPage', web: 'WebPage', service: 'WebPage', area: 'WebPage', article: 'WebPage', faq: 'FAQPage', profile: site.author.publicProfileApproved ? 'ProfilePage' : 'WebPage' };
  const node = { '@type': kinds[page.type] || 'WebPage', '@id': pageId, url, name: page.h1, description: page.description, isPartOf: { '@id': websiteId }, publisher: { '@id': orgId }, inLanguage: 'en-GB' };
  if (page.image) node.primaryImageOfPage = { '@type': 'ImageObject', url: site.domain + page.image };
  if (page.lastTechnicalReview && page.reviewer) node.lastReviewed = page.lastTechnicalReview;
  const graph = [org, website, node];
  if (page.path !== '/' && page.breadcrumb?.length) {
    const id = url + '#breadcrumbs';
    graph.push({ '@type': 'BreadcrumbList', '@id': id, itemListElement: page.breadcrumb.map((item, index) => ({ '@type': 'ListItem', position: index + 1, name: item.label, item: site.domain + item.path })) });
    node.breadcrumb = { '@id': id };
  }
  if (page.type === 'service' || page.type === 'area') {
    const id = url + '#service';
    graph.push({ '@type': 'Service', '@id': id, name: page.h1, description: page.answer, provider: { '@id': orgId }, areaServed: { '@type': page.areaName ? 'Place' : 'City', name: page.areaName || 'London' }, url, serviceType: page.areaName ? 'Unvented cylinder service enquiries' : page.h1 });
    node.mainEntity = { '@id': id };
  }
  if (page.type === 'article') {
    const id = url + '#article';
    const article = { '@type': 'TechArticle', '@id': id, headline: page.h1, description: page.answer, mainEntityOfPage: { '@id': pageId }, publisher: { '@id': orgId }, author: { '@id': orgId }, inLanguage: 'en-GB' };
    if (page.datePublished) article.datePublished = page.datePublished;
    if (page.dateModified) article.dateModified = page.dateModified;
    if (page.image) article.image = site.domain + page.image;
    const citations = (page.sourceIds || []).map(id => site.sources[id]?.url).filter(Boolean);
    if (citations.length) article.citation = citations;
    graph.push(article); node.mainEntity = { '@id': id };
    // A personal byline is used only when the page itself records an approved actual author.
    if (page.authorName && site.author.publicProfileApproved === true && page.authorName === site.author.name) article.author = { '@id': root + '#yassi' };
  }
  if (site.author.publicProfileApproved === true && (page.type === 'profile' || page.authorName === site.author.name)) {
    const person = { '@type': 'Person', '@id': root + '#yassi', name: site.author.fullName || site.author.name, jobTitle: site.author.role, worksFor: { '@id': orgId }, url: root + 'author/yassi' };
    if (site.author.photo) person.image = site.domain + site.author.photo;
    const sameAs = [site.author.linkedin, site.author.x].filter(x => typeof x === 'string' && /^https:\/\//.test(x));
    if (sameAs.length) person.sameAs = sameAs;
    if (site.author.credentials?.length) person.hasCredential = site.author.credentials;
    graph.push(person);
    if (page.type === 'profile') node.mainEntity = { '@id': person['@id'] };
  }
  if (page.type === 'collection' && page.links?.length) {
    const id = url + '#itemlist';
    graph.push({ '@type': 'ItemList', '@id': id, itemListElement: page.links.map((item, index) => ({ '@type': 'ListItem', position: index + 1, name: item.label, url: site.domain + item.path })) });
    node.mainEntity = { '@id': id };
  }
  if (page.faqs?.length) {
    const questions = page.faqs.map(f => ({ '@type': 'Question', name: f.question, acceptedAnswer: { '@type': 'Answer', text: f.answer } }));
    if (page.type === 'faq') node.mainEntity = questions;
    else graph.push({ '@type': 'FAQPage', '@id': url + '#faq', url: url + '#faqs', isPartOf: { '@id': pageId }, mainEntity: questions });
  }
  return { '@context': 'https://schema.org', '@graph': graph };
}
export function sitemap(site, pages, options = {}) {
  const origin = site.domain.replace(/\/$/, '');
  const selected = options.production === true ? pages.filter(page => page.indexable && (!page.approvalRequired || site.author.publicProfileApproved)) : [];
  const escape = s => String(s).replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;').replace(/'/g, '&apos;');
  return '<?xml version="1.0" encoding="UTF-8"?>\n<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">\n' + selected.map(page => '<url><loc>' + escape(origin + page.path) + '</loc>' + (page.dateModified ? '<lastmod>' + escape(page.dateModified) + '</lastmod>' : '') + '</url>').join('\n') + '\n</urlset>\n';
}

const clean = value => String(value || '').trim();
const line = value => clean(value).replace(/[\r\n]+/g, ' ');
export function validateEnquiry(data) {
  const errors = {};
  if (clean(data.name).length < 2 || clean(data.name).length > 100) errors.name = 'Enter your name, up to 100 characters.';
  const phone = clean(data.phone).replace(/[\s()-]/g, '');
  if (!/^(?:0\d{9,10}|(?:\+44|0044)\d{9,10})$/.test(phone)) errors.phone = 'Enter a UK telephone number.';
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(clean(data.email)) || clean(data.email).length > 254) errors.email = 'Enter a valid email address.';
  if (!/^(?:GIR\s?0AA|[A-Z]{1,2}\d[A-Z\d]?\s?\d[A-Z]{2})$/i.test(clean(data.postcode))) errors.postcode = 'Enter the full property postcode.';
  if (!clean(data.service) || clean(data.service).length > 100) errors.service = 'Choose the service you want to discuss.';
  if (clean(data.symptoms).length < 10 || clean(data.symptoms).length > 1500) errors.symptoms = 'Describe the symptom in 10 to 1500 characters.';
  if (data.contactPermission !== true) errors.contactPermission = 'Confirm the contact details may be used to answer this enquiry.';
  return errors;
}
export function buildEnquiryDraft(site, data) {
  const errors = validateEnquiry(data);
  if (Object.keys(errors).length) return { errors, subject: '', body: '', mailto: '', status: 'invalid' };
  const subject = 'Cylinder enquiry - ' + line(data.postcode).toUpperCase() + ' - ' + line(data.service);
  const body = ['Hello G3 Qualified Engineer London,', '', 'I would like to discuss an assessment and availability.', '', 'Name: ' + line(data.name), 'Phone: ' + line(data.phone), 'Email: ' + line(data.email), 'Postcode: ' + line(data.postcode).toUpperCase(), 'Service: ' + line(data.service), 'Equipment make/model: ' + line(data.model).slice(0, 160), 'Symptoms: ' + clean(data.symptoms), 'Access / preferred time: ' + line(data.access).slice(0, 200), '', 'I understand that this enquiry does not confirm a booking.'].join('\n');
  const target = 'mailto:' + site.email + '?subject=' + encodeURIComponent(subject) + '&body=' + encodeURIComponent(body);
  return { errors: {}, subject, body, mailto: target.length <= 1800 ? target : '', status: 'draft-prepared', notice: 'Draft prepared. Send it using your email application, or copy the text into webmail. It has not been sent by this website.' };
}
